# Carnet-de-recette

Carnet de recettes HelloFresh : scan des box le vendredi, préparation des recettes par
Claude Cowork, et en cuisine des tâches réparties entre deux cuisiniers, lues à voix haute
par segments.

- [`docs/cadrage.md`](docs/cadrage.md) : décisions validées, architecture, lots de réalisation
- [`docs/google-cloud.md`](docs/google-cloud.md) : configuration Google Cloud pas à pas
- [`docs/publication.md`](docs/publication.md) : essayer une version (aperçu) et la publier
- [`CLAUDE.md`](CLAUDE.md) : règles pour les agents

Usage privé : ce dépôt ne contient que du code, aucun contenu HelloFresh.

## Installer

L'app ne passe pas par le Play Store. La dernière version est dans les
[Releases](https://github.com/JRRocks/Carnet-de-recette/releases/latest) ; une fois installée,
elle se met à jour toute seule.
