# Recette sur le téléphone

La liste unique de ce que seul ton téléphone peut montrer. Une ligne par point, dans l'ordre
d'un vendredi puis d'un repas. Réponds par le numéro : « R2 bon », « R5 défaut : … ».

États : `à essayer`, `bon` (date), `défaut` (date, tes mots).

| N° | Depuis | Ce que tu fais | Ce que tu dois voir | État |
|---|---|---|---|---|
| R1 | 0.8 | Installer l'APK et ouvrir l'app (c'est la première fois que cette version réduite tourne sur un vrai téléphone) | L'accueil « Semaine » s'affiche et l'app ne se referme pas | à essayer |
| R2 | 0.3 | Vendredi : « Scanner les box », viser l'étiquette d'une box | Son numéro s'affiche en grand, le téléphone bipe, la box apparaît avec le nom du plat | à essayer |
| R3 | 0.3 | Scanner les autres box à la suite, puis « Terminer » | Une ligne par box sous « Vendredi », sans doublon, avec le bon nombre de personnes | à essayer |
| R4 | 0.3 | Ouvrir une recette dans le Carnet | La photo, les ingrédients pour le bon nombre de personnes, les étapes | à essayer |
| R5 | 0.6 | « Envoyer les recettes », choisir Drive | Android propose Drive ; le fichier `recettes-…json` arrive dans le dossier choisi | à essayer |
| R6 | 0.6 | Dans Claude, lancer le skill carnet-semaine | Un compte rendu, et un fichier `semaine-…json` sur le Drive | à essayer |
| R7 | 0.6 | Samedi : « Importer la semaine », choisir ce fichier sur le Drive | « Semaine importée », puis « Ce soir : la … » sur l'accueil | à essayer |
| R8 | 0.6 | Le même import sur le second téléphone, qui n'a rien scanné | La même semaine ; les noms des plats arrivent après quelques secondes | à essayer |
| R9 | 0.6 | Cuisine : « Découpe » sur un téléphone, « Chauffe » sur l'autre, puis « Commencer mes tâches » | Chaque téléphone lit ses propres tâches à voix haute | à essayer |
| R10 | 0.3 | En séance : « C'est fait », « Relire », puis ouvrir le micro et dire « suivant », « répète » | La voix lit, avance et répète ; le micro comprend sans toucher l'écran | à essayer |
| R11 | 0.3 | Lancer un minuteur, éteindre l'écran, attendre la fin | La sonnerie part à l'heure, écran éteint | à essayer |
| R12 | 0.6 | Aller au bout d'une recette | « Recette terminée » ; sur l'accueil, « Ce soir » passe à la suivante | à essayer |
| R13 | 0.3 | Mode secours : « Photographier la fiche », recto puis verso | Les deux pages s'enregistrent, avec le nombre de blocs lus | à essayer |
| R14 | 0.8 | Après la première publication : rouvrir l'app | La ligne « La version … est prête », puis l'installation par-dessus, données gardées | à essayer, après D3 |
